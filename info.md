Regroupez les éléments de la sidebar Home Assistant en **menus dépliables** avec contrôle d'accès par rôle.

## Fonctionnalités

- Groupes dépliables / repliables avec animation fluide
- Les éléments ajoutés à un groupe disparaissent du menu principal
- 3 niveaux de rôle : **Administrateur**, **Utilisateur**, **Visiteur**
- Panel de configuration dédié dans la sidebar (admins uniquement)
- Export / Import JSON pour partager la configuration
